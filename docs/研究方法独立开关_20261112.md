# 研究方法独立开关

设置页已由整套预设选择改为按环节选择。参考桌面《论文调研智能体_最终版.pptx》第 10、11、18 页，候选排序、全文转换与单篇分析保持不同环节；同一篇内检索环节中的混合、级联方案互斥。

| 环节 | 关闭时的基线 | 开启时 |
|---|---|---|
| 论文来源 | arXiv + OpenAlex | 额外加入 Crossref |
| 候选排序 | 语义 / RRF 融合 | 在原前 20 篇中加 Cross-Encoder 联合重排 |
| 全文转换 | legacy 解析 | CPU layout 版面解析，异常可回退 |
| 单篇分析 | 整篇直接分析 | 全文证据先行、篇内混合检索、篇内级联检索、实验性分段并发中选一 |
| 多篇调度 | 顺序执行 | 对话输入区原有“并行优化”，独立于上述方法 |

全文证据先行保留全部提供原文；混合与级联是选段检索的两种替代方案，级联的直接技术对照为混合检索。篇内分段并发与多篇论文并行不等同。界面保留真实证据范围及实验限制说明，不将所有替代方案标为已经证明更好。

修改后需点击“保存研究方法”，只作用于后续任务。全部恢复基线先更新草稿，再保存；已经提交任务的设置快照不变。保存研究方法不清除未保存的模型参数或凭据草稿。

## 原九个选项的含义

| 原选项 | 实际设置 |
|---|---|
| 启动时配置 | 启动环境或已有配置，不是固定的一项技术 |
| 基线 | 双源、语义融合、legacy、整篇直接分析 |
| 仅新增来源 | 基线上加入 Crossref |
| 仅联合重排 | 基线上开启 Cross-Encoder |
| 仅版面解析 | 基线上选择 layout |
| 篇内证据检索 | 基线上以混合检索选段分析 |
| 级联证据检索 | 基线上以级联检索选段分析 |
| 全文证据分析 | 基线上保留全文、引句先行并核对位置 |
| 综合增强 | 同时启用 Crossref、联合重排、layout，仍整篇直接分析 |

旧 profile 仍供历史记录及 CLI 兼容；界面不再要求选择预设。新组合保存为 custom，并保存四项实际控制值；旧预设的值由后端解析后显示，不猜测启动配置。旧后台没有这些字段时明确提示重启服务，禁止用假定值覆盖旧配置。
