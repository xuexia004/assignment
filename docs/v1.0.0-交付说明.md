# Paper Agent v1.0.0 交付说明

本版在现有 Electron + React + Python MCP 架构上增量交付。研究执行保持 MainAgent → 官方 MCP Client → MCP Server，API 仍为 v3。

## 当前行为

- 多源检索、合并去重和语义融合排序后，将前 20 篇完整标题与摘要交给任务 Agent；不足 20 篇则全部传入。其余候选仍可在 PDF 获取失败时按排名替补。
- 输入区“并行优化”开关关闭时显式顺序执行，开启后采用有界并发；并发数沿用设置。开关只影响新任务，提交或运行中禁用。
- 性能页显示所属任务的实际执行方式、阶段耗时、语义 Top-k 余弦相似度和 Agent Top-k 筛选分数。
- 研究笔记、原文 Markdown 和 PDF 原文为同级阅读入口；执行记录保持折叠，原始失败和审计数据保留。
- 作者关键词只接受明确的元数据或已取得 PDF 的显式关键词栏目。摘要不为输入预算静默截断。

主要实现位于 `services/pipeline.py`、`agents/selector_agent.py`、`services/author_keywords.py`、`services/semantic_reranker.py`，以及前端的 `Conversation.tsx`、`workspaceStore.ts`、`MetricsPanel.tsx` 和阅读组件。文档、测试与版本元数据同步更新。

## 两次真实实验

[实验记录](并行优化真实实验_20261102.md)与[可公开的测量 JSON](experiments/20261102-concurrency.json)保留问题、参数、Top-k、耗时、用量、输入指纹、PDF 哈希及质量差异。

- 顺序：257.77 秒；并行：141.08 秒。本次总耗时下降 45.27%，观察到的加速比 1.83×。
- 两次均为 32 篇去重候选、20 篇 Selector 输入、相同的三篇精选与相同 PDF；下载/转换缓存命中均为 0。
- 两次均取得三份 PDF、三份 Markdown、三份带论文级正文的笔记，以及一份部分报告，最终交付均为 `preliminary_notes`。
- 通过校验的分块为顺序 16/21、并行 14/21；`summary_scope=fulltext` 的笔记从一份变为零份。额外质量门槛没有全部通过，失败结果完整保留。

本次发布依据用户授权的“时间明显下降”条件。没有把一次时间下降解释为研究质量提升，也没有为得到更好数字追加真实实验。单次配对仍受模型输出和网络波动影响。
