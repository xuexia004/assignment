# 并行优化真实实验 · 2026-11-02

同一案例各运行一次，顺序执行 **257.77 秒**，并行执行 **141.08 秒**，本次总耗时下降 **45.27%**，观察到的加速比 **1.83×**。

## 实验设置

- 研究问题：大语言模型的不确定性估计如何判断何时应该拒答？请比较关键方法的校准方式、评测指标和适用局限，提出一个小规模可验证的研究方向。
- 固定英文检索词：`large language model uncertainty estimation for abstention`。两次均走显式 query，跳过查询规划的模型生成，避免检索词变化。
- MainAgent → 官方 MCP Client → MCP Server → arXiv / OpenAlex → 去重与语义融合排序 → 前 20 篇交给任务 Agent → Top-3 → PDF / Markdown / 笔记 / 报告。
- 模型：`deepseek-v4-flash`；thinking 关闭；每来源每条查询最多 20 篇；并发数 3。
- 两次分别启动新服务，使用空的独立论文目录，关闭下载与转换缓存；两次缓存命中均为 0。模型、分析分块与调用预算保持一致。
- 先顺序运行，再开放前端开关并并行运行。后端复用现有的有界并发；开关让用户显式选择顺序或并行。
- 两轮研究执行时的版本标记为 0.3.0；完成实验后才调整发布元数据为 1.0.0，研究算法和提示词未在两轮之间修改。
- 顺序 Job：`b4d75ba247a34a7b905b06e46a899320`；并行 Job：`c61be0c84af640aa9a524482cc43d58d`。

## 发布决定与实际边界

- 用户要求在时间明显下降时上传 v1.0；按实验前约定的 25% 耗时门槛，本次 45.27% 的降幅满足这一条件。
- 额外设置的质量门槛没有全部通过：通过引文校验的分块从 16 个降至 14 个，fulltext 范围笔记从 1 份变为 0 份；三份笔记均保留论文级正文，但并行轮全部标记为 partial_fulltext。原始附加门槛的失败结果保留在 JSON 中。
- 两轮均为部分报告，不宣称完成全部全文分析或质量等价。无效引文、模型输出及受限综合均保留原始错误。一次配对实验不能排除模型输出和网络时延波动，也不能替代多轮统计基准。
- 发布按用户的耗时条件推进，软件检查另行记录；没有为改变实验结果追加真实研究或重跑失败样本。
